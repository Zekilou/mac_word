# 整个软件 UI 重构设计（信息架构 + 组件体系 + 交互模式）

> 日期：2026-08-11
> 范围：macOS 原生 SwiftUI 背单词应用的**前端整体重构**（信息架构、全局壳、页面布局、组件体系、控件能力）
> 前置：功能保持，不新增业务能力；纯 UI/交互层重构；数据层（ECS）不动

## 1. 背景与动机

当前 UI 是一步步拼出来的，存在四类问题：

1. **大数量级词库（GRE 18474 词）选词场景 UI 怪异**：选词清单一次加载 5000 词且用非懒加载 VStack 全量渲染（卡顿）；已选标签墙无上限（爆开铺满面板）；无搜索定位能力；380 宽设置面板要塞下全部功能（拥挤、滚动别扭）。
2. **信息架构松散**：7 个一级 Tab（词库/词汇/RSS/创作/背诵/分析/设置）平铺，无层级心智；功能组织不符合用户"数据 / 学习 / 设置"的直觉。
3. **组件零复用**：各页面自绘样式（自绘 tab、分段、不同布局），搜索/列表/统计/词块等能力各写一遍，行为不一致、无法统一演进。
4. **缺统一设计语言**：未遵循 Apple 设计原则与平台规范，无组件分层。

目标：前端整体重构——**统一信息架构（三区）**、**统一组件体系（L0-L3 + 七族控件）**、**统一交互模式**，并解决大数量级场景。

## 2. 设计原则

三层原则共同指导（哲学层 + 平台规范层 + 普适可用性层）：

### 2.1 Apple 设计原则（HIG 2026 版，映射）
- **Simplicity 简洁 + 层级**：每个界面只放必要控件；主路径（搜索/过滤/随机/生成）一眼可见，次要内容（已选详情、计划、策略）折叠
- **Familiarity 熟悉 + 一致**：使用系统标准组件外观（搜索框、scope chips、勾选标记、交替行），全局交互一致
- **Agency 主动权**：已选可随时单项移除/一键清空；条件随时可改；不锁流程；错误可撤销
- **Purpose 聚焦**：选词、生成是主路径，给足空间；设置/配置为次要层级

### 2.2 Nielsen 可用性启发式（映射）
- **状态可见性**：已选计数、当前过滤条件、结果数量、任务进度实时可见
- **辨识而非回忆**：已选词始终可展开查看；搜索让大词库"可辨识"而非靠记忆
- **用户控制与自由**：移除/清空/改条件即时生效
- **一致性**：勾选、搜索、清空等交互全局一致
- **错误预防**：随机数量钳制、重复选词去重
- **灵活性与效率**：常用操作一键可达；支持批量
- **极简设计**：去冗余控件

### 2.3 macOS 平台规范（HIG）
- 搜索框置顶、边输入边搜、scope bar 过滤明确分类
- 大列表交替行背景；选中行用勾选标记
- 行文本简洁（词 + 一行释义）；结果上限 + 懒加载

## 3. 信息架构

### 3.1 三区导航

一级导航只分三区，所有具体功能归入子区（二级）：

| 一级 | 二级子区 |
|---|---|
| **数据** | 词库 \| 词汇 \| 同义词 \| RSS 源 \| 分析 |
| **学习** | 创作 \| 阅读 \| 背诵 |
| **设置** | 模型 \| 通用 \| 储存 \| 显示 |

- **数据** = 内容数据的仓库与管理（词的导入/掌握度/映射、阅读源、数据洞察）
- **学习** = 学习活动（创作生成文章、阅读、复习）
- **设置** = 系统配置

### 3.2 双栏侧边栏

- 左侧**一级导航**（数据/学习/设置）：图标 + 文字行，选中高亮，可折叠为图标栏；折叠按钮始终可见（hamburger/sidebar.toggle）
- 紧邻**二级导航**（当前一级的子区）：与一级同款行样式（图标 + 文字 + 选中高亮），联动显示当前一级下的子区
- 内容区在最右

```
┌────────┬────────┬──────────────────────┐
│ 一级    │ 二级    │ 内容区               │
│ 数据 ◎  │ 词库    │  [子区页面]          │
│ 学习    │ 词汇    │                     │
│ 设置    │ 同义词  │                     │
│        │ RSS源   │                     │
│        │ 分析    │                     │
└────────┴────────┴──────────────────────┘
```

### 3.3 全局壳

- **禁用原生标题栏**：内容延伸到顶部（保留系统红绿灯）；窗口根层沿用 NSVisualEffectView（.headerView + .behindWindow）
- **全局状态 = 顶部悬浮胶囊**：位于标题栏安全区，悬浮于三分栏之上（不占布局）
  - 折叠态：只显示一个（最新/汇总任务：图标 + 标题 + 进度 + 停止）
  - 展开态：竖向排列显示全部任务（每个 = 图标 + 标题 + 进度 + 状态 + 取消）
  - 空闲时隐藏
- 三分栏最左（一级）可折叠

## 4. 页面布局

### 4.1 数据区

**词库**
```
┌───────────┬─────────────────────────────────┐
│ 词库列表   │ [🔍 搜索卡片 ][排序▾][N]         │ ← 数据浏览工具条
│ 导入词库…  │ 卡片列表（可搜索列表组件，懒加载） │
│ TOEFL(402)│ ☐ abandon   放弃；抛弃           │
│ GRE(18474)│ ☐ abduct    绑架                │
└───────────┴─────────────────────────────────┘
  点击卡片 → popover 详情（词性/音标/释义/例句/同义词/出现过的文章）
```
- 左词库列表（220，行=名称+卡片数）| 右工具条 + 卡片列表；详情 popover

**词汇**
- 顶部掌握度概览卡组（已会/不会/出现过/未标记，常驻）
- 页面内分段：初始化段落（词块流式 + 图例 + 计数 + 提交）/ 已记录词汇（工具条：搜索 + 状态 chips + 排序 + 列表，点击可改掌握度）

**同义词**
- 左：搜索候选 + 添加映射（左词/右词/权重/来源）| 右：已建映射列表（行 + 删除）

**RSS 源**
- 源列表（内置 + 自定义，增删/刷新）

**分析**
- 掌握度分布环形图 + 复习趋势（折线：每日复习量/AGAIN 率）+ 弱词排行（比例条 TOP10）

### 4.2 学习区

**创作**（主路径）—— Finder 式多列布局（横向多列、不挤）

```
┌───────┬────────┬────────┬──────────────────┬────────────┐
│ 主题   │ 生成方式│ 选词器  │ 生成过程（含结果摘要）│ 文章        │
│ [主题] │ [分段]  │ [🔍搜索]│ 当前阶段          │ ┌────────┐ │
│ ───── │ [模型]  │ [状态chips]│ 思考日志       │ │阅读区  │ │
│ 目标词 │ [配置]  │ 随机批量 │ 指标             │ │(高亮) │ │
│ [选词] │        │ 清单勾选 │ [停止]           │ └────────┘ │
│ [✨生成]│        │         │ ──────────────── │            │
│       │        │         │ 结果摘要           │            │
│       │        │         │ (覆盖/策略/计划)    │            │
└───────┴────────┴────────┴──────────────────┴────────────┘
                                          (overlay 历史抽屉 250)
```

- 列1 主题（含已选概览 + 生成按钮，260 固定）| 列2 生成方式（200）| 列3 选词器（320，可展开/收起）| 列4 生成过程（260，含结果摘要）| 列5 文章（flex 最宽）
- 列间分隔线**可拖拽调宽**（Finder 式，自定义 DragGesture 实现；每列有 min/max）；开发先固定档位跑通，再验证拖拽稳定性
- 历史 = **overlay 覆盖抽屉**（右侧滑入），非 column
- 页面内分段：造文 | 改写（改写复用相同骨架：源文输入列 / 目标词列 / diff 列 / 历史抽屉）

**阅读**
- 左（270）：来源切换（RSS 源 / 生成历史）+ 文章列表（可搜索列表）
- 右：阅读区（词块流式 + 标记会/不会/出现过 + 图例 + 打开原文）

**背诵**
- 统计卡组（词库/已学/今日到期/今日已复习/AGAIN 率）+ 闪卡（正/背面翻转）+ 4 键评分（快捷键 1-4）

### 4.3 设置区

| 子区 | 内容 |
|---|---|
| **模型** | 生成方式（档位：进程内本地/远端 LLM）；远端服务（类型/模型名/地址/API Key）；生成参数（嵌入验证强度/temperature/最大输出字数）；进程内模型（目录选择、模型列表 + 量化档一键下载（进度/暂停/续传/取消）、从 Ollama 提取、当前选用模型） |
| **通用** | 复习调度（SM-2/FSRS）；生成默认（默认目标词数量/默认文章字数）；选词默认（默认过滤范围/随机数量默认值）；**关于**（版本信息/版权/开源致谢/诊断导出） |
| **储存** | 数据存储（数据库位置/大小）；模型存储（目录/占用）；空间清理（删除未用模型/清空历史文章） |
| **显示** | 外观（跟随系统/浅色/深色）；阅读（文章字号/词块高亮样式）；列表密度（紧凑/常规） |

## 5. 组件体系

### 5.1 分层

```
L0 系统原子   SwiftUI 自带（按钮/TextField/Picker/ProgressView/Charts）
L1 基础组件   无业务依赖，可独立构建（A-G 七族）
L2 组合组件   依赖 L1：可搜索列表三件套、选词器、已选概览、生成过程面板、diff、详情面板
L3 页面       数据区 5 子区 + 学习区 3 子区 + 设置区 4 子区（组装 L1+L2）
```

### 5.2 七族控件（L1）

- **A 输入**：单行/多行文本框、数字输入、密码框、搜索框（清除+边输边搜）、选择器（下拉/分段/Menu/scope chips）、勾选框、表单分组
- **B 展示**：标题/正文/描述文本、KV 行、统计卡组、计数徽标、比例条、chips/标签墙/状态色点/图例、列表行（普通/词+释义/带操作）、懒加载列表、网格、流式展示族（流式文本/流式+高亮/标记剥离/结束态）、折叠展示（DisclosureGroup）、diff 视图
- **C 反馈**：线性/不确定进度、阶段步骤条、字节进度、实时指标行、任务状态项（进行中/成功/失败/取消/暂停）、状态横幅、空态/无结果/加载中
- **D 操作**：按钮族（主/次/危险/图标/链接）、快捷键提示、tooltip、刷新/清空/全选/暂停续传取消
- **E 容器**：抽屉、popover、sheet、alert、卡片容器、分组容器、分栏、工具栏
- **F 数据浏览工具条**：搜索框 + 状态筛选 chips + 排序菜单 + 结果计数 + 加载更多/上限提示（组合级，多页复用）
- **G 图表**：环形/饼图（掌握度分布）、柱状（每日复习）、折线（AGAIN 率趋势）、排行条（弱词 TOP）、图表图例/空数据态（Swift Charts）

### 5.3 核心复用三件套

**可搜索列表**（卡片列表/同义词候选/已记录词汇/选词器 复用）：
- `筛选查询服务`：按词形/释义前缀+子串 + 状态过滤 + 上限，SQL 按需查询（走 GraphQueries 命名方法，复用 `idx_comp_text_text_a` NOCASE 索引）
- `已选集合 store`（CRUD）：add / remove / toggle / removeAll / contains / count，@Observable
- `列表视图组件`：搜索框 + chips + 懒加载列表 + 勾选标记 + 空态/无结果

**词块流式**（初始化段落/RSS 阅读/文章阅读 复用）：词块流式布局 + 状态色（会/不会/出现过）+ 可点击标记，基于现有 ReadFlowLayout

**统计卡组**（掌握度概览/背诵统计/复习统计 复用）

## 6. 控件能力清单

每个 L1 控件的定义能力（行为契约）：

| 控件 | 能力 |
|---|---|
| 搜索框 | 输入即筛；清除按钮；placeholder；结果计数联动 |
| scope chips（状态过滤） | 单选切换；与搜索条件叠加；当前条件可见 |
| 排序菜单 | 选项化排序；可反向；与列表联动 |
| 勾选行 | 点击整行切换；勾选标记反馈；支持批量 |
| 已选集合 | 增/删/清空/查询/计数；去重；跨页保持 |
| 统计卡组 | 数值+标签；多列排布；数值格式化 |
| 进度族 | 线性确定/不确定/阶段步骤/字节/指标行；暂停续传态 |
| 任务状态项 | 进行中/成功/失败/取消/暂停 图标+文字 |
| 空态/无结果 | 引导文案；与"加载中/有数据"三态区分 |
| 抽屉 | overlay 覆盖滑入；标题栏+收起；不挤压内容 |
| 流式展示 | 打字机追加；实时高亮；标记剥离；结束态接管 |
| 折叠展示 | 默认收起；内容高度受限内滚（防撑高窗口） |
| 词块 | 流式换行；状态色；可点击；图例联动 |
| 图表 | 数据驱动；空数据态；图例 |

## 7. 分期实施

- **期 1 · 全局壳 + 基础组件库**：三区导航/双栏侧边栏/悬浮胶囊/无标题栏；L1 七族控件（A-G）落地
- **期 2 · 数据区**：可搜索列表三件套 + 数据区 5 子区（词库/词汇/同义词/RSS 源/分析）
- **期 3 · 学习区**：创作 Finder 多列（含选词器、生成过程列、overlay 历史）+ 阅读 + 背诵
- **期 4 · 设置区 + 收尾**：设置 4 子区（含关于）+ 图表完善 + 全局回归

## 8. 工程约束

- 文件 ≤300 行（拆组件文件，历史超限文件只增量改）
- **禁用 List 与 HSplitView 拖拽**（macOS 27 beta 崩溃规避）：列表用 ScrollView + LazyVStack；列宽拖拽用自定义 DragGesture，先固定档位跑通再验证稳定性
- UI 不写 SQL：查询走 GraphQueries 命名方法
- 模块化：筛选查询/已选集合/列表组件为独立模块，多页复用
- 不引入新依赖（图表用系统 Swift Charts）
- Swift 6 并发 / @MainActor 零警告；TDD（VM 逻辑可单测）；build 0 warning

## 9. 待验证风险

- 自定义列宽拖拽在 macOS 27 beta 的稳定性（若不稳定回退固定档位）
- 悬浮胶囊在标题栏安全区的 hit 区域与红绿灯不冲突
- 大词库搜索 SQL 性能（复用 NOCASE 索引，需实测）
